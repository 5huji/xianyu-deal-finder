🐟 闲鱼好价分析助手 手机版

在闲鱼网页版搜索页一键运行：自动过滤无效商品，输出最低价 Top10 与性价比 Top5。纯本地分析，不上传数据。

📖 第一次用？

照着图文攻略一步步来，两分钟搞定。

📖 打开图文使用攻略

📱 方案 A（推荐）：Kiwi 浏览器版

装好之后每次用零操作：在闲鱼搜完商品，点右下角 🔍 好价分析 就行，不用输书签、不用折腾。

  1. 去应用商店安装 Kiwi Browser（免费，支持 Chrome 扩展）。
  2. 在 Kiwi 里点 ⋮ → 扩展程序，从 Chrome 应用店安装 Tampermonkey（如果菜单里没看到，就在地址栏输入 chrome://extensions 回车）。
  3. 在 Kiwi 里点下面的按钮，Tampermonkey 会自动弹出安装页，点安装。
🦎 一键安装脚本（请在 Kiwi 里打开）

之后在 Kiwi 里打开闲鱼网页版登录、搜索，按钮会自动出现。脚本自动更新。

🔖 方案 B：Chrome 书签版（不想装新浏览器用这个）

下面四步是给 Chrome 用的，一次设置：

第一步：复制书签代码

点一下按钮复制书签代码（只有一百多个字符），下一步把它存成浏览器书签。以后功能升级不用重新复制，会自动更新。

第二步：存为书签

安卓 Chrome

  1. 随便打开一个网页 → 点右上角 ⋮ → 书签 → 添加书签
  2. 长按刚添加的书签 → 修改
  3. 把网址那一栏全部删掉，粘贴刚才复制的代码，名称改成 🔍闲鱼好价 → 保存

iPhone Safari

  1. 随便打开一个网页 → 点底部分享按钮 → 添加书签
  2. 打开书签列表 → 右下角编辑 → 点刚添加的书签
  3. 把地址全部删掉，粘贴刚才复制的代码 → 完成

第三步：在闲鱼网页登录

用手机浏览器打开闲鱼网页版并登录（只需一次，登录态会保留在浏览器里）。

🌊 前往闲鱼登录

第四步：开始用

  1. 在闲鱼网页版搜索商品（关键词越具体越好，如 airpod4 降噪版）
  2. 点浏览器地址栏，输入 闲鱼好价，点击弹出的书签
  3. 它会自动滚动加载（约20秒），然后滑出分析报告，点标题直达商品页

把本页放到手机桌面

安卓 Chrome：点 ⋮ → 添加到主屏幕
iPhone Safari：点分享按钮 → 添加到主屏幕

以后点桌面图标就到这儿，再跳去闲鱼分析。
