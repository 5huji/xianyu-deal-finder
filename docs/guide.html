🔖 方案 B（备选）：Chrome 书签版

不想装新浏览器，就用 Chrome + 书签。步骤：

  1. 打开安装页，点 📋 复制书签代码（新版只有一百多字符）。
  2. 在安装页点地址栏 ☆ 存成书签 → ⋮ → 书签 → 找到它 → ✏️ 修改。
  3. 名称改成 闲鱼好价，网址整段删掉后粘贴代码，返回保存。
  4. 在 Chrome 里打开 goofish.com 登录、搜商品 → 点地址栏输入 闲鱼好价 → 点书签运行。

?常见问题

  • 按钮没出现（方案A） → 确认 Tampermonkey 里脚本是启用状态；刷新闲鱼搜索页；确认网址是 goofish.com/search。
  • 点了书签没反应（方案B） → 99% 是旧代码，重新复制新版短代码替换书签网址。
  • 提示"请先完成闲鱼登录" → 在浏览器里打开 goofish.com 登录一次即可。
  • "没抓到有效数据" → 关键词太冷门，换更常见的词再搜。
  • 下单前 → 点标题进详情页核对价格和成色，报告只是帮你缩小范围。
