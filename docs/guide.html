📖 闲鱼好价分析 · 手机图文攻略

以 vivo + Chrome 为例，一次设置好，以后每次用只需 3 步。先花 2 分钟看完再动手。

!开始前先自查（30秒）

  • 之前复制过旧版代码？旧代码已失效，必须按下边第一步重新复制新的，替换掉书签里的网址。
  • 运行分析时，当前页面必须是闲鱼搜索结果页（网址里有 goofish.com/search）。
  • Chrome 里打开过 goofish.com 并登录（只需一次）。

1复制书签代码

打开安装页，点 📋 复制书签代码，看到 ✅ 已复制 就行。新代码只有一百多个字符。

2存成书签并粘贴代码

  1. 还在安装页，点地址栏的 ☆，把本页存成书签。
  2. 点 Chrome 右上角 ⋮ → 书签，找到刚存的书签，点旁边的 ✏️ 修改。
  3. 名称改成 闲鱼好价（四个字，以后地址栏一输就能找到）。
  4. 网址整段删掉，粘贴刚才复制的代码只有一行。
  5. 返回即保存。
⚠️ 网址栏必须全部删干净再粘贴，前面不能留 https:// 之类的残留。代码以 javascript: 开头就是对的。

?常见问题

  • 点了书签没反应 → 99% 是旧代码。回到第一步重新复制，替换书签网址。
  • 提示"请先完成闲鱼登录" → 在 Chrome 里打开 goofish.com 登录一次即可。
  • "没抓到有效数据" → 关键词太冷门，换更常见的词再搜。
  • 想分析别的商品 → 直接在闲鱼搜新关键词，地址栏再运行一次书签就行。
  • 下单前 → 点标题进详情页核对价格和成色，报告只是帮你缩小范围。
