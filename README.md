# 闲鱼好价分析助手 🐟

一个油猴（Tampermonkey）脚本：在闲鱼网页版搜索页点一下按钮，自动滚动加载多页搜索结果，过滤无效商品，输出**价格最低 Top10** 与**性价比 Top5**，每条附推荐理由和直达链接。

## 它帮你做什么

- 🔍 自动滚动加载多页搜索结果（约 8 页）
- 🧹 智能过滤：求购帖、单只/补配、普通版（当你搜"降噪版"时自动排除非降噪）、文不对题、钓鱼低价、其他品牌
- 💰 **价格最低 Top10**：按价格排序，附"比中位价低 X%"等理由
- ✨ **性价比 Top5**：综合价格偏离度 + 成色（全新未拆/九成新/有维修史等）打分
- 📊 统计面板：共抓取 N 条、有效 M 条、同类中位价、过滤明细

## 安装

1. 浏览器安装 **Tampermonkey** 扩展（Chrome / Edge 扩展商店搜索即可）
2. 打开本仓库的 `xianyu-deal-finder.user.js` 文件页，点击 **Raw**，Tampermonkey 会自动提示安装，点击"安装"
   - 脚本开启了自动更新，后续优化会自动同步
3. 完成

## 使用

1. 打开 https://www.goofish.com/ 并登录你的闲鱼账号
2. 搜索你想买的商品（关键词越具体越好，如 `airpod4 降噪版`、`索尼 WH-1000XM5`）
3. 点页面右下角的 **🔍 好价分析** 按钮，等待自动滚动加载完成（约 20 秒）
4. 右侧面板查看报告，点标题直达商品详情页
5. 下单前请手动进详情页再核验一次成色、是否在售（脚本只分析搜索页可见信息）

## 工作原理

- 通过 Hook 页面自身的搜索接口（mtop）捕获结构化商品数据，DOM 抓取做兜底
- 过滤与排序算法纯本地运行（见 `analyze` 函数），不上传任何数据
- 低频操作（一次分析约滚动 8 页），请遵守闲鱼用户协议，勿高频使用

## 已知限制

- v1 只分析搜索页可见信息（标题/价格/图片），"想要人数""发布时间"等详情页字段需手动点进去看
- 闲鱼改版页面结构后脚本可能需要更新（欢迎提 Issue）
